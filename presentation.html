📖 Comment utiliser le site

Pour les clientes :

  1. 1

    Parcourir le catalogue

    Les clientes visitent terangashein.com et voient tous les produits disponibles avec photos et prix.

  2. 2

    Ajouter au panier

    Elles cliquent sur "Ajouter au panier" pour chaque article voulu. Le panier s'affiche en bas de l'écran.

  3. 3

    Choisir le paiement

    Depuis le panier, elles choisissent Wave, Orange Money, ou WhatsApp pour finaliser leur commande.

  4. 4

    Payer et confirmer

    Le montant exact est pré-rempli. Elles scannent le QR code ou cliquent le lien pour payer directement.

Pour Teranga (recevoir les commandes) :

  • 📱 Les commandes WhatsApp arrivent sur le numéro +221 77 539 95 84 avec le détail complet et les photos des articles
  • 💸 Les paiements Wave arrivent directement sur le compte Wave +221 77 539 95 84
  • 🟠 Les paiements Orange Money arrivent sur le compte Orange Money +221 77 539 95 84
🛍️ Ajouter ou modifier des produits

Les produits sont gérés dans le fichier app.js sur GitHub. Pour ajouter un nouveau produit, il faut modifier ce fichier. Chaque produit contient : nom, prix, catégorie, taille(s), et photos.

  1. 1

    Ouvrir GitHub

    Aller sur github.com/ahmadoubambandaw/Terangashein → fichier app.js

  2. 2

    Ajouter la photo

    Téléverser la photo du produit dans le dossier /images/ sur GitHub

  3. 3

    Ajouter le produit

    Copier un produit existant dans app.js, modifier le nom, prix, catégorie et lien photo

  4. 4

    Déploiement automatique

    Après sauvegarde sur GitHub, Netlify redéploie automatiquement en 1-2 minutes
